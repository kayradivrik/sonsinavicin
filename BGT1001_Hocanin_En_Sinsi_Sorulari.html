Tuzak 1-5: Slayt 1 & 2 Satır Arası Detayları

          
    
            
  • C, C++, C# Hangi Seviye? Yüksek Seviyeli değil, slaytta Ortak Seviyeli Diller grubundadır! (Yüksek Seviyeli: FORTRAN, Pascal, Basic, COBOL).
    • 
            
  • Pasta / Fırın Örneği: Fırının kaç derece ve ne zaman açıldığı belirsizliği algoritmanın Kesinlik/Belirleyicilik kuralını bozar.
    • 
            
  • ASCII Özel Karakterler: 0-31 ve 127 yazılamayan özel karakterlerdir (128 değil!).
    • 
            
  • Akış Şeması Ok Yönleri: Karşılaştırma (baklava) ve Döngü (altıgen) şekillerinde koşul sağlanıyorsa SAĞDAKİ ok, sağlanmıyorsa ALT (aşağıdaki) ok izlenir.

Tuzak 6-10: Slayt 3 Operatör ve Veri Tipi Sırları

          
    
            
  • ^ Operatörünün İki Görevi: Slaytta hem Üs Alma hem de Özel Veya (XOR) işlemi yaptığı vurgulanır.
    • 
            
  • C++ vs Java char Boyutu: C++'da char 1 byte, Java'da ise 2 byte yer kaplar!
    • 
            
  • C++'da long Neden Kullanılmaz? 16-32-64 bit mimari farklarından dolayı int ile aynı hale geldiği için yeni mimarilerde kullanılmaz (Java'da ise 8 byte'tır).
    • 
            
  • string C Dilinde Var mı? Hayır! C'de tanımlı değildir, C++'a sonradan (string.h) eklenmiştir ve bellekte 8 byte yer kaplar.
    • 
          

        


        

          
Tuzak 11-15: Slayt 4 & 5 Kod İçi Çeldiriciler

          
    
            
  • cin.get(x) Tuzağı: Klavyeden "1993" veya "Merhaba" girilse bile sadece ilk haneyi ('1' veya 'M') char olarak alır.
    • 
            
  • ++x vs x++: Tek başına satırda fark yoktur; ama sonra = sayi2++; satırında önce eski değer atanır, sonra değişkeni artışı görmez!
    • 
            
  • Mantıksal Çıktı: C++ cout ekrana 1 / 0 basar; Java println ise true / false basar.
    • 
            
  • return Altındaki Kod: Derleme hatası vermez ama return görüldüğü an altprogram biter, altındaki satırlar ölü koddur.
    • 
          

        


        

          
Tuzak 16-20: Slayt 6 & 7 Karar ve Döngü Tuzakları

          
    
            
  • switch-case Yasakları: float ve double kesinlikle kullanılamaz (veri kaybı nedeniyle). < ve > kullanılamaz.
    • 
            
  • do-while Scope (Kapsam) Hatası: while(sayi != 0); içinde kontrol edilen sayi değişkeni do { } içinde tanımlanırsa derleme hatası verir; döngü dışında tanımlanmalıdır!
    • 
            
  • Çoklu for Ayracı: for(int a=0, b=20; a<=20 && b>=10; a+=2, b--) -> Ana bölmeler ; ile, değişkenler ve artışlar , ile ayrılır!
