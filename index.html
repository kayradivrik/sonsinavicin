            1. Slayt: Hatalar, Diller ve Sayı Sistemleri
          

          
    
            
  • Algoritma 3 Kuralı: Kesinlik/Belirleyicilik (şansa bağlı olmamalı), Sonluluk (belirli adımda bitmeli), Genellik (tüm ihtimalleri kapsamalı).
    • 
            
  • Syntax Error: Dil kurallarına aykırı yazım; derleyici satırını rapor eder, çözümü en kolay hatadır.
    • 
            
  • Run-time Error: Çalışma anında olmayan dosya/bellek erişimi; işletim sistemi programı keser.
    • 
            
  • Mantık Hatası: İşlem önceliği/parantez hatası; programı durdurmaz ama yanlış sonuç üretir, bulması en zordur.
    • 
            
  • 5 Dil Seviyesi: 1) Çok Yüksek (Visual Basic, Access, Foxpro), 2) Yüksek (FORTRAN, Pascal, COBOL), 3) Ortak Seviyeli (C, C++, C#), 4) Alçak (Assembler), 5) Makine Dili (0-1).
    • 
            
  • Taban Dönüşümü: 2-8 arası sağdan sola 3'lü grup (4-2-1), 2-16 arası 4'lü grup (8-4-2-1, A=10..F=15).
    • 
          

        


        

          

            
            2. & 3. Slayt: Akış Şemaları, Tarihçe, IDE ve Veri Tipleri
          

          
    
            
  • ASCII: 'A' = 65 (01000001). 0-31 ve 127 yazılamayan özel karakterlerdir.
    • 
            
  • 8 Akış Şekli: Elips (Başla/Dur), Paralelkenar (Veri Girişi), Dalgalı Dörtgen (Çıktı), Dikdörtgen (Matematiksel İşlem), Eşkenar Dörtgen (Karşılaştırma), Altıgen (Döngü: Başlangıç, Bitiş, Artış), Çift Çizgili Dikdörtgen (Dış Fonksiyon).
    • 
            
  • Tarihçe: C (1972, Dennis Ritchie, UNIX), C++ ilk adı "C with Classes". Java (1995, James Gosling, Sun, kahve ismi, bytecode + JVM sayesinde "Bir kere yaz her yerde çalıştır").
    • 
            
  • IDE Kısayolları: Dev C++ (F9 Derle, F10 Çalıştır, F11 Derle+Çalıştır). Eclipse (Ctrl+F11 Çalıştır, sysout + Ctrl+Space).
    • 
            
  • Veri Tipleri: short (2B, -32768..32767, unsigned: 0..65535), int (4B), float (4B, 7 hane duyarlı, Java'da F takısı), double (8B, 15 hane), bool (1B).
    • 
          

        


        

          

            
            4. & 5. Slayt: Girdi/Çıktı, ++/-- İstisnası ve Fonksiyonlar
          

          
    
            
  • C++ Girdi/Çıktı: #include <iostream> ve using namespace std;. cin.get(x) ne girilirse girilsin sadece ilk karakteri okur!
    • 
            
  • Java Scanner: import java.util.Scanner; → nextInt(), nextDouble(), next().
    • 
            
  • ++sayi1 vs sayi2++ Tuzağı: Atama işleminde öndeyse (y = ++x) önce arttırır sonra atar; arkadaysa (y = x++) önce eski değeri atar sonra arttırır!
    • 
            
  • Mantıksal Çıktı Farkı: C++ ekrana 1 ve 0 basarken, Java true ve false basar.
    • 
            
  • Fonksiyon/Metot: Dönüş yoksa void. return görüldüğü anda fonksiyon biter, altındaki satırlar asla çalışmaz. Java'da public static zorunludur.
    • 
          

        


        

          

            
            6. & 7. Slayt: Karar Yapıları, Recursive ve Döngüler
          

          
    
            
  • Parantezsiz if Tuzağı: Süslü parantez {} yoksa if sadece altındaki ilk satırı kontrol eder, 2. satır her durumda çalışır!
    • 
            
  • switch-case Kuralları: float ve double ile kullanılamaz! < veya > kontrolü yapılamaz (sadece eşitlik). break; unutulursa alttaki tüm case'ler çalışır.
    • 
            
  • Recursive (Özyineleme): Kendi kendini çağıran altprogram. 1) Koşul Bloğu (bitiş kontrolü, örn: sayi == 1), 2) Yineleme Bloğu (sayi * F(sayi - 1)).
    • 
            
  • do-while Farkı: Koşul sonda kontrol edilir, şart sağlanmasa bile en az 1 kez çalışır ve sonunda noktalı virgül while(kosul); zorunludur! Koşulda kullanılan değişken döngü dışında tanımlanmalıdır.
